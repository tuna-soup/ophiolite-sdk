# Scientific workflow rules

Use the public SDK. Run `ophiolite skills path` and read the relevant installed
guide before a live workflow. Never inspect credential files to copy tokens into
prompts, logs, scripts or notebooks. Synthetic fixture credentials are test-only.

Read the exact permitted revision, preserve missing values/units/depth reference,
and validate before publication. A calculation is local script-declared execution.
Do not infer conversions, align axes silently, broaden access or claim a server job.
Publishing and sharing must follow the user's requested action. Keep the private
work folder and command identities; recover from it after a lost reply. After
`ShareOutcomeUnknown`, read grants first and do not repeat sharing automatically.
Report refusals plainly, including how the user can recover. Never claim that a
synthetic test proves a live customer source or identity-provider deployment.
